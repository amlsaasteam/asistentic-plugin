# LOT-900 — Registrar anulación de venta
## Qué cambia
El cajero puede anular una venta dentro de los 10 minutos siguientes.
## Criterios de aceptación verificables
- CA-1: Una venta con más de 10 minutos no se puede anular y devuelve error 409.
- CA-2: Una venta ya anulada no se anula dos veces.
- CA-3: La anulación queda registrada con usuario y fecha.
## Estimación
Pequeña
